# JJ Performance

PWA de treino, evolução e coach de Jiu-Jítsu com periodização de 16 semanas. Funciona no navegador e pode ser instalado na tela inicial do celular.

Site: https://brunocremtn-sketch.github.io/jj-performance/

## Instalar

### Android (Chrome)

1. Abra o site no Chrome.
2. Toque no menu (⋮).
3. Toque em **Adicionar à tela inicial** ou **Instalar app**.

### iPhone (Safari)

1. Abra o site no Safari.
2. Toque em **Compartilhar**.
3. Toque em **Adicionar à Tela de Início**.
